# 03 — Browse from Shared home to a Travel note

**What to build:** Give desktop readers one complete navigation journey from a
clear Shared home through the authored Travel area and meaningful folder groups
to a real note, with location and return paths always visible.

**Blocked by:** 02 — Resolve authored titles and wikilinks.

**Status:** ready-for-agent

- [ ] The Shared home shows exactly Travel, Shared Finance, Pets, Life Planning, and Household Inbox.
- [ ] No unselected Knowledge Base area or known sentinel appears on the home page.
- [ ] Each area label and route comes from staged content, with the authored area index used as its introduction.
- [ ] Selecting Travel opens the authored Travel area rather than a generic folder listing.
- [ ] Travel pages are grouped by meaningful folder structure, including upcoming trips, past trips, and preferences when present.
- [ ] Lists stay bounded to the Travel journey and do not introduce broad type collections.
- [ ] A persistent desktop sidebar provides access to the five Shared areas.
- [ ] The sidebar clearly identifies the active area and current page.
- [ ] Breadcrumbs expose the current folder ancestry and return to the correct parent.
- [ ] Opening a nested Travel note and using browser Back returns through the journey without redirects or a custom history stack.
- [ ] Direct navigation to the home, Travel area, and nested note routes works from the static export.
- [ ] The article uses one primary heading, a comfortable reading measure, and a clear heading hierarchy.
- [ ] Semantic navigation and main landmarks are present.
- [ ] A production-browser test covers Shared home → Travel → nested group → real note → breadcrumb or Back.
- [ ] Existing staging security and Quartz rollback tests remain intact.
