# 02 — Add Light / Dark / System appearance

**What to build:** Let a reader choose Light, Dark, or System appearance in the refreshed Web Projection. Follow the device by default and remember an explicit choice across visits.

**Blocked by:** 01 — Refresh the Web Projection reading interface.

**Status:** ready-for-agent

- [ ] A visible, keyboard-operable control offers Light, Dark, and System with a clear accessible name and current state.
- [ ] With no saved choice, the reader follows the device theme; System also responds to later device theme changes.
- [ ] An explicit choice is saved locally and restored on a later visit.
- [ ] Page, navigation, links, code, tables, focus, and interaction states remain readable in both appearances on desktop and phone.
- [ ] The reader remains a generic static export; verify appearance and persistence manually without adding theme CI tests.
