# Domain docs

This is a single-context repository.

## Read before work

- Read `docs/vocabulary.md` for canonical terms.
- Read each relevant `docs/adr-*.md` architectural decision.
- Read the Publication Manifest contract before changing publication or
  staging behavior.

If a document does not exist, proceed without proposing an empty placeholder.

## Vocabulary

Use the canonical terms in issue titles, specifications, tests, and code. In
particular, distinguish a Knowledge Base, Web Projection, Publication
Manifest, Allowlist, and Knowledge Web Publisher.

Do not introduce a synonym when the vocabulary already defines the concept.
Record a genuine language gap for domain-modeling work.

## Architectural decisions

Flag conflicts with an accepted ADR explicitly. Do not silently replace an
accepted boundary or decision.
